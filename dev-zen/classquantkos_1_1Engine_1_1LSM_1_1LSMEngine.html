Detailed Description

template<KI::OptRight OptRight, KI::LSRegressionBasis Basis = KI::LSRegressionBasis::LaguerreP03>
class quantkos::Engine::LSM::LSMEngine< OptRight, Basis >

Core template processing structural steps of the Longstaff-Schwartz American valuation induction.

Note
Operations are split between high-throughput data reduction on the Device (GPU) and matrix linear algebra solutions on the Host (CPU) to maximize processing performance.
  • ### Mathematical Overview & Execution Split:
  1. Device Phase 1 (Kokkos::parallel_reduce): Screens all simulation lines to isolate components that are currently In-The-Money. Evaluates polynomial basis configurations and aggregates entries into a structural matrix $M$ and vector $B$.
  2. Host Pass (CPU Linear Algebra): Performs Tikhonov regularization on the tiny $NBasis \times NBasis$ matrix and solves for the regression weights $C = M^{-1}B$ via explicit Cholesky decomposition.
  3. Device Phase 2 (Kokkos::parallel_for): Evaluates expected continuation values using the completed regression weights, compares values against immediate exercise payoffs, and updates the path cash flow vectors.

inlinestatic

STEP 4: Applies the final discount factor from $t = 1$ to $t = 0$.

  • Multiplies the remaining optimal cash flow trajectories by the final discount factor to bring all values back to time zero.
  • Parameters
    d_best_future_outcomes1D cash flow target view matrix vector.
    discount_factorFinal continuous discount factor fraction step value.
    Applies the final discount factor from $t = \Delta t$ to $t = 0$ and evaluates the optimal immediate exercise decision at day zero ($t = 0$).

Unlike historical time steps where asset prices are scattered across different locations (requiring a conditional regression curve), all simulated paths at $t = 0$ originate from the exact same initial conditions ($S_0$ and $v_0$). Because $S_0$ is a uniform scalar, the continuation value collapses from a conditional expectation ($E[Y|X]$) into a global unconditional expected value ($E[Y]$).

This function executes a two-phase day-zero evaluation:

  1. Parallel Discount & Reduction (Kokkos::parallel_reduce): Multiplies every path's cashflow by the final discount_factor and simultaneously aggregates the total sum to compute the statistical mean continuation value ($\bar{Y}$).
  2. Global Exercise Check: Evaluates the intrinsic payoff of exercising immediately at $S_0$. If intrinsic_today > mean_continuation, it indicates that waiting is disadvantageous on average, so the entire path vector is globally overwritten with intrinsic_today. Otherwise, the discounted future cashflows are preserved.

This pattern avoids hardware warp divergence on the GPU while maintaining rigorous consistency with rational option exercise boundaries.

inlinestatic

Computes an intercept-only regression fallback when standard Cholesky decomposition fails.

In the Longstaff-Schwartz Method, regressions fail when the covariance matrix is singular (e.g., multicollinearity from paths bunching together) or when there are fewer In-The-Money (ITM) paths than basis functions. In these cases, estimating the conditional expectation $E[Y|X]$ is mathematically impossible.

Instead of returning zeroed coefficients (which forces an artificial $0.0$ continuation value and triggers incorrect early exercise on every ITM path), this fallback computes the Best Unbiased Estimator: the unconditional expectation $E[Y]$.

Because the 0-th Laguerre polynomial is a constant ($L_0(X) = 1$), sums.B(0) contains the pure sum of all discounted future cashflows. Dividing this by sums.count yields the statistical mean ($\bar{Y}$). Setting $\beta_0 = \bar{Y}$ and all other coefficients to $0.0$ draws a flat horizontal line, safely reverting the time-step to a European holding baseline and preserving path stability.

Parameters
sumsAggregated regression matrix and vector entries computed on the device.
Returns
A Coeffs structure with $\beta_0$ set to the mean continuation value, and zeroes elsewhere.

◆ solve_system_on_host_cholesky()

template<KI::OptRight OptRight, KI::LSRegressionBasis Basis = KI::LSRegressionBasis::LaguerreP03>
Coeffs< NBasis > quantkos::Engine::LSM::LSMEngine< OptRight, Basis >::solve_system_on_host_cholesky ( const RegressionSums< NBasis > & sums)
inlinestatic

Solves the system of normal equations ($M \cdot C = B$) on the CPU host via Cholesky decomposition.

  • Applies Tikhonov regularization ($\text{reg} \cdot I$) to the matrix diagonal to ensure positive-definiteness and numerical stability, then resolves the coefficient vector $C$ using standard forward and backward substitution:
  1. Decomposition: $M = L \cdot L^T$
  2. Forward Substitution: $L \cdot y = B$
  3. Backward Substitution: $L^T \cdot C = y$
  • Parameters
    sumsAggregated regression matrix and vector entries computed on the device.
    Returns
    A populated Coeffs structure containing the solved weights. If the matrix is singular or there are fewer ITM paths than basis functions, it returns a statistical mean fallback (first coeff = mean, other coeffs set to zero).
