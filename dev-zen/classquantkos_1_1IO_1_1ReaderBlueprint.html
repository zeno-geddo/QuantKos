Detailed Description

Abstract base class (interface) defining the contract for reading path data back into memory.

  • This blueprint establishes the interface for streaming or reading simulated price paths from disk.
  • ### Lifecycle & Slicing Safeguards Since this is an interface intended for polymorphic usage, all copy and move operations are explicitly deleted.
