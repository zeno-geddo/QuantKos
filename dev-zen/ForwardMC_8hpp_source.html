QuantKos v0.1.0 (Beta)
QuantKos is a high-performance Monte Carlo option pricing engine written in modern C++20 and built on top of the Kokkos performance portability framework. It provides a single-source implementation capable of targeting serial execution, multi-core CPUs, and modern GPUs while maintaining the same code base.

87 MCResults get_option_prices() const {
88 // NOTE : the total number of simulations are performed in batches to handle cases when not enough memory is available
89 // NOTE : The global random number pool is created once. States advance dynamically. So using the same pool for different batches is the correct approach
90
91 // 1. Initialize Helper Classes needed during the MC (keep in this local function scope)
92 PathsMCBatchMem BatchMem(config); // Handles the Memory
93 RNGManager RNGen(config); // Handles the Random number (Must initialize here and not in the batch loop!!!)
94 MSolver<ModelPolicy, SchemePolicy, OptType, OptRight> Solver(config); // Handles the Temporal integration
95 OptionPricer OPricer(config); // Handles the Option Pricing
96 KIO::OutputManager OWriter(config); // Handles the outputs
97 ForwardMCProgressTracker MCTracker(config, BatchMem);
98
99 // Print Pre-Execution Diagnostics
100 MCTracker.print_pre_execution_diagnostic();
101 OWriter.print_paths_info_planned_outputs();
102
103 // 3. Run all batches forwards (all mc simulations giving the prices)
104 run_mc_forward(BatchMem, RNGen, Solver, OPricer, OWriter, MCTracker);
105
106 // 4. Compute Option Price
107 OPricer.evaluate_option_price();
108 OPricer.print_info_option_price();
109 MCResults Res{config, OPricer.get_option_price_data()};
110 return Res;
111 }
