Detailed Description

template<size_t NBasis = 4>
struct quantkos::Engine::LSM::RegressionSums< NBasis >

Aggregator structure used during Kokkos parallel reductions.

  • Combines the matrix $M$, vector $B$, and an In-The-Money (ITM) pathway sample counter into a single structure. This allows a single reduction pass over the path matrix.
  • Template Parameters
    NBasisThe number of basis functions (polynomial order + 1).
