Detailed Description

template<KI::OptType OptType, KI::OptRight OptRight>
struct quantkos::Engine::PayoffTracker< OptType, OptRight >

Unified compile-time state accumulator and payoff resolver for path-dependent contracts.

  • This structure is designed to handle multiple option types (European, Asian, Barrier variants, Lookbacks, and Binaries) inside parallel GPU simulation loops.
  • Template Parameters
    OptTypeCompile-time option structure classification index.
    OptRightCompile-time option execution right (Call or Put).

Resolves the final option payoff function based on accumulated price statistics.

  • Evaluates the contract value at the end of the timeline according to its specific financial payoff rules:
  • Asian: Based on the arithmetic path average $\bar{S} = \frac{1}{N} \sum S_t$.
  • Barrier: Evaluates the payoff if the path activation or knock-out conditions are met.
  • Lookback (Fixed): Substitute extrema price into the standard payoff function.
  • Lookback (Floating): Evaluates floating strike parameters $\max(S_T - S_{\min}, 0)$ or $\max(S_{\max} - S_T, 0)$.
  • Binary: Returns a fixed cash unit (1.0) or asset value if finishing in-the-money.
  • Parameters
    STerminal spot price of the underlying asset ($S_T$).
    StrikeTarget fixed execution strike price ($K$).
    BarrierPriceTrigger boundary price for activation or knock-out conditions ($H$).
    n_t_stepsTotal discrete time integration steps executed along the timeline.
    Returns
    The resulting option payoff value.
