Detailed Description

template<size_t NBasis = 4>
struct quantkos::Engine::LSM::Matrix< NBasis >

Represents the covariance matrix $M = X^T X$.

  • Allocated entirely on the stack within execution threads to track cross-product combinations of polynomial functions evaluated along asset price paths.
  • Template Parameters
    NBasisDimension of the square regression system (The number of basis functions (polynomial order + 1)).
