Detailed Description

High-performance file reader that loads price path data from saved binary files.

Note
Instead of loading massive files entirely into memory, it uses mathematical stride equations to "jump" directly to specific columns in the file, extracting only the price slice needed.

Extracts the cross-sectional spot prices across all simulated paths at a target timeline coordinate.

Note
Automatically translates the continuous time request (e.g., $t = 0.5$ years) into the closest discrete time-step index, checks system boundaries, and reads the targeted prices directly from disk.
Parameters
current_timeThe target timeline coordinate in years (e.g., 1.5).
Returns
A standard vector containing the loaded spot prices at that time across all paths.
Exceptions
std::runtime_errorIf the file stream is closed, if the requested time falls outside of the simulated timeline, or if the request does not align with the discrete time step (dt).
