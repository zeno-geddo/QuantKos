Detailed Description

Fixed metadata header placed at the absolute beginning of the saved binary files.

  • This layout acts as an ID card for the file. It allows any reader to instantly verify that the binary data is valid, was generated by QuantKos, and uses the correct number format precision (float vs. double) before loading the actual path matrix payload.
