Detailed Description

template<KI::MathModel ModelPolicy, KI::NumScheme SchemePolicy, KI::OptType OptType, KI::OptRight OptRight>
class quantkos::Engine::ForwardMCRunner< ModelPolicy, SchemePolicy, OptType, OptRight >

Orchestrator for Forward Monte Carlo simulations.

Note
This class serves as the top-level execution container for pricing options that rely exclusively on a forward simulation pass (e.g., European, Asian, Barrier, Lookback, and Binary options). It eliminates runtime polymorphism overhead by embedding structural pricing parameters directly into the type signature.
Template Parameters
ModelPolicyCompile-time stochastic process selection (e.g., Heston, Bates).
SchemePolicyCompile-time SDE integration algorithm (e.g., Euler, Milstein, AndersonQE).
OptTypeCompile-time option payoff structure classification.
OptRightCompile-time option execution right (Call or Put).
Note
To handle cases where the required path matrix exceeds physical memory limitations (such as GPU VRAM), the simulation is chunked into manageable sub-allocations using a batching loop strategy.
