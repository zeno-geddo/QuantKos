Detailed Description

Provides high-performance, compact binary serialization for simulation path data.

This namespace implements the quantkos::IO blueprints using a custom binary format designed for maximum I/O throughput. By bypassing text-based serialization (like CSV), it provides near-native disk write speeds, making it the preferred choice for large-scale Monte Carlo batches.

Binary Format Specification

All files generated by this namespace adhere to the following memory layout:

  • Header (BinHeader): A fixed-size structure at the start of the file containing:
  • Magic Key ('QuantKos') for file validation.
  • Precision metadata (float vs. double) to prevent cross-platform reading errors.
  • Simulation dimensions (Total Paths, Time Steps, $dt$).
  • Payload: A raw, contiguous block of KT::Real data stored in Row-Major order.

Performance Characteristics

  • Direct Memory Mapping: When data layout permits (contiguous row-major), the BinWriter utilizes std::ofstream::write to dump memory buffers directly to disk in single hardware instructions.
  • Strided Reading: The BinReader avoids loading entire files into RAM. It calculates byte-offsets to perform "jumps" to specific time-coordinates within the file, allowing memory-efficient access to partial data.
Note
This implementation assumes system-endianness matches the machine that wrote the file. It is intended for HPC clusters where the read/write environment is uniform.
