Detailed Description

High-performance file writer that serializes simulated asset price paths to disk in binary format.

  • Saves raw memory directly to disk. This is much faster and uses far less storage space than writing numbers as human-readable text files (like CSV or TXT).
  • The writer automatically handles two writing pathways:
  1. The Fast Track (Contiguous): If the device memory layout is contiguous (and with layout right), it writes the entire batch to disk in a single, ultra-fast block transfer instruction.
  2. The Buffered Fallback: If the layout is fragmented, it safely gathers the scattered prices row-by-row into a temporary buffer before writing them to disk.
