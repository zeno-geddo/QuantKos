QuantKos v0.1.0 (Beta)
QuantKos is a high-performance Monte Carlo option pricing engine written in modern C++20 and built on top of the Kokkos performance portability framework. It provides a single-source implementation capable of targeting serial execution, multi-core CPUs, and modern GPUs while maintaining the same code base.

Detailed Description

Namespace containing core mathematical type definitions and compile-time constants.

  • Provides a unified way to manage floating-point precision across the entire QuantKos engine via CMake-defined preprocessor macros.

Typedef Documentation

◆ Real

using quantkos::Types::Real = typedef double

The primary floating-point type used throughout the numerical simulation engine.

  • Defaults to double precision for maximum accuracy. If the CMake option QKOS_ENABLE_SINGLE_PRECISION is enabled during the build process, this alias automatically resolves to float to improve memory bandwidth and throughput on GPU architectures.
