It provides a single-source implementation capable of targeting serial execution, multi-core CPUs, and modern GPUs while maintaining the same code base.

Detailed Description

Utility namespace for handling user-facing console help.

  • Contains functions responsible for outputting startup welcome banners, terminal usage syntax instructions, and structural YAML configuration templates directly to the standard output stream.
