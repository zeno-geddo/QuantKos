QuantKos v0.1.0 (Beta)
QuantKos is a high-performance Monte Carlo option pricing engine written in modern C++20 and built on top of the Kokkos performance portability framework. It provides a single-source implementation capable of targeting serial execution, multi-core CPUs, and modern GPUs while maintaining the same code base.

115 static OptionPricer::MCOpPrices compute_option_price(const KC::UInputs &local_config,
116 PathsMCBatchMem &BatchMem) {
117 // 1. Initialize Helper Classes needed during the MC with the spoofed config (keep in this local function scope)
118 RNGManager RNGen(local_config); // (Because the seed is the same, RNGManager automatically guarantees CRN)
119 MSolver<ModelPolicy, SchemePolicy, OptType, OptRight> Solver(local_config); // Handle SDE evolution
120 OptionPricer OPricer(local_config); // Handles the Option Pricing
121 KIO::OutputManager OWriter(local_config); // Handle Writing Outputs
122 ForwardMCProgressTracker MCTracker(local_config, BatchMem); // Track the MC
123
124 // 2. Print Pre-Execution Diagnostics if needed
125 MCTracker.print_pre_execution_diagnostic();
126 OWriter.print_paths_info_planned_outputs();
127
128 // 3. Run all batches forwards (all mc simulations giving the prices)
129 run_forward_phase(BatchMem, RNGen, Solver, OPricer, OWriter, MCTracker);
130
131 // 4. Evaluate the option prices once the forward phase is done
132 OPricer.evaluate_option_price();
133 OPricer.print_info_option_price();
134
135 // 5. Return the option price and stats
136 return OPricer.get_option_price_data();
137 }
