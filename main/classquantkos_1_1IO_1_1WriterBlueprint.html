Detailed Description

Abstract base class (interface) defining the contract for path and payoff output writers.

  • This blueprint establishes the mandatory interface for writing simulation results to disk. Implementations of this interface (such as binary, CSV, or custom database writers) handle writing simulated asset paths and terminal payoffs during batch execution loops.
  • * ### Lifecycle & Slicing Safeguards Since this is an interface intended for polymorphic usage, all copy and move operations are explicitly deleted.

Saves the current batch of simulated price paths to disk storage if configured.

Note
If required, This function is invoked sequentially at the end of each Monte Carlo batch loop, writing only the active simulation subset to prevent memory-mapped disk overflow.
