Detailed Description

template<size_t NBasis = 4>
struct quantkos::Engine::LSM::Coeffs< NBasis >

Fixed-size container for the calculated ordinary least-squares regression coefficients.

  • Represents the solution vector $C$ of the system: $$M \cdot C = B$$ where $M = X^T X$ is the design covariance matrix, and $B = X^T Y$ is the projected cash flow vector.
  • Template Parameters
    NBasisThe number of basis functions (polynomial order + 1).
