QuantKos v0.1.0 (Beta)
QuantKos is a high-performance Monte Carlo option pricing engine written in modern C++20 and built on top of the Kokkos performance portability framework. It provides a single-source implementation capable of targeting serial execution, multi-core CPUs, and modern GPUs while maintaining the same code base.

50 explicit RNGManager(const KC::UInputs &config) {
51 // Kokkos allocates a massive, flat array of independent mathematical state registers directly inside the device memory space (VRAM or system RAM).
52 // The number of states allocated is chosen by Kokkos to match the maximum physical hardware concurrency of your chip (often tens of thousands of individual slots).
53 // Each slot is initialized with a slightly scrambled version of your seed.
54 uint64_t initial_seed = config.mc.rng_seed;
55 global_rng_pool = GlobalRNGPool(initial_seed);
56 std::cout << " [RNGenerator] Global Random Number Pool initialized correctly." << std::endl;
57 }

83 [[nodiscard]] GlobalRNGPool get_global_rng_pool() const {
84 // Kokkos only creates a shallow copy of the pool wrapper.
