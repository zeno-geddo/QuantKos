Detailed Description

Static utility class responsible for loading and parsing file-based configurations.

  • Provides a centralized static entry point to load YAML/JSON options, validate parameter constraints (such as positive volatility values and non-zero path counts), and map them into the engine's structural configuration representation.
  • Note
    This class acts as a pure stateless utility. Instantiation is disabled to prevent redundant object allocations.
