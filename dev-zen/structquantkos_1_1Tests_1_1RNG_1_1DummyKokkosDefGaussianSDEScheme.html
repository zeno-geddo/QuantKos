Detailed Description

A simplified stochastic differential equation (SDE) scheme used for RNG validation.

This helper scheme isolates the random number generator from actual model dynamics, directly returning standard normal (Gaussian) draws to verify statistical properties.

Note
Use kokkos default box-muller normal rn generator
