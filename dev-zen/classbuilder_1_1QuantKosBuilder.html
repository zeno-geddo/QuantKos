It provides a single-source implementation capable of targeting serial execution, multi-core CPUs, and modern GPUs while maintaining the same code base.

Detailed Description

Builder class to configure, compile, and install the QuantKos option pricing engine.

This class manages the CMake build process, allowing compilation against either pre-installed local dependencies or automatic downloads via FetchContent. It abstracts away the generation of CMake flags based on the desired hardware backend, precision, and math mode.
