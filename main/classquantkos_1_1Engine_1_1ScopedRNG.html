Detailed Description

Device-side tool for managing individual thread random states.

  • The Problem: When a GPU thread wants to generate a random number, it needs to "check out" a unique random state from the global pool, use it, and then "return" it when it finishes. If a thread forgets to return it (or crashes), that state is locked forever (a state leak).
  • The Solution: This class uses RAII (Resource Acquisition Is Initialization). It automatically checks out a state the moment it is created, and its destructor guarantees the state is returned back to the pool the exact moment the thread finishes its work, no matter what happens.
